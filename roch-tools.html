Roch Tools

PC tools made by Roch Studio.

Roch Viewer

A read-only memory-controller and timing viewer for Windows. It reads the memory controller, the modules, the board, and the CPU directly, and shows what they actually report — the timings the controller was programmed with, the training results it settled on, and the sensors that move while the machine runs. It changes no setting.

Supported platforms

  • Intel LGA1700 (Z690/Z790) — DDR5 and DDR4
  • Intel LGA1851 (Z890) — DDR5
  • AMD AM5 / Granite Ridge — DDR5

What it shows

  • Summary — machine identity, the clock chain, and the timings worth seeing at a glance
  • System Info — OS, CPU with code name and process node, board, chipset, Super I/O, and each module's SPD identity
  • Timings — primary, secondary and tertiary, plus refresh, command, power-down and bus groups, read from both memory controllers side by side
  • Skew — RTT, ODT and RON, VREF levels, per-group drive strengths and slew compensation, ODT latencies, and the DFE taps
  • Misc — per-channel read latencies, ECS state, controller feature switches, preamble and postamble settings, and the DDR5 mode registers
  • Telemetry — live clocks per logical processor, temperatures, package and core power, board voltages, GPU, and each DIMM's PMIC rails, each with min, max and average
  • Advanced — every row in one searchable list, filtered as you type

Requirements

  • Windows 10 or 11, 64-bit, run as administrator
  • inpoutx64.dll from Highresolution Enterprises, placed beside the EXE — it is not bundled. Without it the program still opens, but register-backed rows read nothing and say so.

Free and open source (GPL-3.0).

Roch NVRAM

A Windows editor for AMI SCEWIN NVRAM exports. It reads the live NVRAM, lets you queue setting changes, and writes them only after a backup, a fresh re-export confirming nothing moved, and a value-by-value verification afterwards. It is the SCEWIN round trip with a review step in the middle — you see exactly which settings will change before anything is written.

Warning: this program writes firmware settings. Incorrect voltage, clock, memory, security, or boot values can stop a machine from starting. Keep Clear CMOS or BIOS Flashback available before you use it.

What it does

  • Export and Import — the SCEWIN round trip as two buttons, with the queued changes shown in between
  • Preflight checks — the import refuses to run if the HII CRC changed, a queued setting went missing, its value changed since you queued it, or it became ambiguous
  • Backup and verification — a timestamped backup before every import, then every requested value is checked afterwards
  • NVRAM tab — the full table with Setting, Help String, Token, Offset, Width, BIOS Default and Value, searchable and filterable. Settings the parser cannot read unambiguously are greyed out rather than guessed at
  • Pending Changes tab — before and after for every queued change, exportable as a modified nvram.txt or a transaction JSON
  • Compare tab — diff two NVRAM files by token, offset and width, with a CSV export
  • Log tab — a catalog of every NVRAM opened, archived and content-addressed by SHA-256
  • Load NVRAM — restore settings from a saved file after a Clear CMOS; every difference is queued as a normal change, so the same checks apply
  • Offline mode — a dry run that never touches firmware and needs no administrator rights

Requirements

  • Windows, run as administrator
  • Nothing to install — Python and Qt are inside the executable. Bundled AMISCE 5.05.01.0002

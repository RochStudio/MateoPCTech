Roch Tools

PC tools made by Roch Studio.

Roch Viewer

Read-only memory-controller and timing viewer for Windows. Shows what the controller, modules, board and CPU actually report — timings, training results and live sensors. It changes no setting.

  • Platforms — Intel LGA1700, LGA1851, and AMD AM5
  • Shows — timings, skew, telemetry, and a searchable advanced list
  • Needs — Windows 10/11 x64 as administrator, plus inpoutx64.dll beside the EXE

Free and open source (GPL-3.0).

Roch CPU

Board-independent CPU and memory tuning for Intel LGA1700 and AMD Ryzen (Zen 2 to Zen 5): ratios, voltages, power limits, Curve Optimizer, and per-DIMM DDR5 rails.

Warning: bad values can crash or damage hardware. Changes do not survive a reboot.

  • Intel — ratios, OC mailbox voltages, PL1/PL2, DDR5 VDD/VDDQ/VPP
  • AMD — PPT/TDC/EDC, PBO scalar, Curve Optimizer, FMax, DDR5 rails
  • Needs — Windows 10/11 x64 as administrator, .NET 8 (or self-contained build)

Free and open source (GPL-3.0).

Roch GPU

Afterburner-style GPU tuning for NVIDIA and AMD from one executable: clocks, voltage, power limit, fan control, V/F curve, monitoring and profiles. No kernel driver.

Warning: writing clocks and voltages can crash or damage hardware.

  • Controls — clocks, limits, voltage, fan curve, Extreme OC (off by default)
  • Also — live monitor, five profiles, built-in CLI
  • Needs — Windows; administrator for writes. Self-contained EXE

Free and open source (GPL-3.0).

Roch NVRAM

AMI SCEWIN NVRAM editor for Windows. Queue setting changes, then write only after a backup, preflight checks and value-by-value verification.

Warning: writes firmware settings. Keep Clear CMOS or BIOS Flashback ready.

  • Safe write path — backup, preflight, verified import
  • Also — searchable NVRAM table, compare, offline dry-run
  • Needs — Windows as administrator; Python/Qt bundled

Free and open source (GPL-3.0).

Download 1.0.1 View on GitHub

Roch Stress Test

One window for Prime95, y-cruncher, TestMem5, RAM Test Pro, Linpack, OCCT, Cinebench, memtest_vulkan and 3DMark 11 — with presets, time limits and live failure detection.

Warning: these tests push hardware hard. Watch temps; do not leave a first run unattended.

  • Quick Start — one test at a time from tool cards
  • Failure detection — watches logs/console; saves failed-run transcripts
  • Needs — Windows as administrator; third-party tools beside the EXE

Free and open source.

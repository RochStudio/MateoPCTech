Roch GPU

A lightweight Windows overclocking and undervolting utility for AMD Radeon cards. It reads your card, driver version, vBIOS, and VRAM on launch, then puts the voltage curve, clocks, power limit, and fans in one compact window — no bloated suite needed.

Features

  • Voltage offset (mV) — undervolt by dropping the whole curve; 0 is stock
  • Core and memory clock offsets in MHz
  • Power limit adjustment by percentage offset
  • Memory timing control, including fast timing
  • Fan control — fixed speed percentage, plus a Zero RPM toggle for silent idle
  • Built-in monitor and log for sampling clocks and watching the active limiter
  • Apply, Revert, and Reset so you can back out of a bad setting instantly
  • Five profile slots that can auto-apply at logon
